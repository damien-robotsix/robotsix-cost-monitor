## Stuck-ticket detection (new feature)
- `clients/mill.py` — `MillClient` queries `GET /tickets` on robotsix-mill board API, identifies tickets in non-terminal states (draft, human_issue_approval, ready, etc.) older than `stuck_ticket_threshold_hours`. Raises `MillAPIError` on failure.
- `app.py` — `_stuck_ticket_loop()` background task started in lifespan. On `MillAPIError` preserves previous gauge value. Logs warning with stuck ticket details.
- `routes.py` — `GET /api/stuck-tickets` returns fresh results, 503 on MillAPIError. `_CHAT_SKILL` needs manual update to document endpoint (src/ blocked).
- `metrics.py` — `stuck_ticket_check_runs_total` (Counter), `stuck_ticket_count` (Gauge).
- Config: `mill_base_url`, `mill_api_key` (SecretStr), `stuck_ticket_threshold_hours` (48, 0=disable), `stuck_ticket_check_interval_seconds` (600).
- Tests: `test_mill.py` (client unit tests), `test_app.py` (gauge handling in loop).

## CostService cache (current)
- Single unified in-memory TTL cache (SWR) keyed by `(project_slug, window_hours)`, holding a `WindowData` snapshot with all five data kinds: traces, model_usage, backend_cost, agent_usage, trace_count. Fetched as a unit via `asyncio.gather`.
- `DASHBOARD_WINDOW_PRESETS = (1, 6, 24, 168)` — pre-warmed by `_warm_cache` at startup and by `_cache_refresh_loop` (cadence `dashboard_refresh_interval_seconds`, default 120s).
- Stale-while-revalidate: fresh served immediately, stale served + bg refresh, cold miss blocks. `POST /api/refresh` invalidates all keys. `last_updated` is a single per-refresh timestamp.
